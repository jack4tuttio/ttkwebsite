# Flagged — Roblox Safety Directory

## Uploading to GitHub

Upload every file and folder in this project to the root of your repository.

Your repository should look like:

```text
.github/
  workflows/
    pages.yml
app.js
build.mjs
flagged.txt
index.html
style.css
README.md
```

Then open:

**Repository Settings → Pages → Build and deployment → Source → GitHub Actions**

Open the **Actions** tab and run **Build and deploy website** once.

## Editing flagged.txt

Each account uses one line:

```text
USER_ID|CATEGORY 1, CATEGORY 2|SUMMARY|DATE|STATUS
```

Example:

```text
261|Scamming, Impersonation|Community-submitted report summary.|2026-07-27|Flagged
```

Use the numeric Roblox user ID. Do not add an evidence column.

## Important

Listings are community reports, not official Roblox findings. Use neutral wording,
verify submissions, provide a correction/appeal process, and do not encourage harassment.
